# Indicaciones:

Desarrolle el siguiente enunciado de problema utilizando el lenguaje de programación web PHP. Haga un sitio web básico con HTML5, use CSS y componentes de base de datos.

La arrendadora de autos “Machine Line” le ha solicitado un sitio web, que tenga estos links.

* A cerda de
* Mostrar autos (por modelo o todos)
* Agregar autos

## Consideraciones:

* La **opción 1** es informativa y a criterio del desarrollador (según su creatividad).
* La **opción 2** debe tener un formulario donde se pueda seleccionar los autos por modelo o todos. Luego al aparecer los registros, se debe poder actualizar o eliminar según sea el caso.
* La **opción 3** haga **un solo formulario** que permita agregar los datos en las tablas **autos y clientes**.
* La BD ha de llamarse **semestral**.
* La tabla **autos** debe contener los campos:
  * Placa
  * Marca
  * Modelo (SEDAN, PICK-UP, SUB, BUSITO)
  * Kilometraje
  * Id cliente
* La tabla **clientes** debe contener los campos:
  * Id cliente
  * Nombre cliente
